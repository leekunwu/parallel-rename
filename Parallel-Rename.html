사용 가이드

파일 세트 가져오기

파일을 창에 놓으세요. 두 번째 세트부터 추가를 누르면 새 파일 열이 생깁니다. 바꾸기는 기존 파일 열 전체를 교체합니다.

열 순서와 실행 취소

열 제목을 드래그해 순서를 바꾸고, 더블클릭해 이름을 바꾸세요. 파일 열끼리, 이름 구성 열끼리 이동합니다. 되돌리기 ⌘/Ctrl+Z, 다시 실행 ⌘/Ctrl+Shift+Z를 지원합니다. 텍스트 입력 중에는 브라우저 기본 텍스트 실행 취소가 적용됩니다.

선택과 편집

클릭하거나 드래그해 셀을 선택하세요. 열 제목은 열 전체, 행 번호는 행 전체, 왼쪽 위는 표 전체를 선택합니다. ⌘/Ctrl+C는 선택한 값을 복사합니다. 이름 셀은 더블클릭 또는 Enter로 편집하고 Esc로 선택 상태에 돌아갑니다. 파일 순서 변경 중에는 파일을 드래그해 이동합니다.

이름 구성과 저장

파일을 가져온 순서는 브라우저가 전달한 순서입니다. 각 파일 열의 순서를 직접 확인하세요. 순서 변경 모드에서는 개별 파일을 목록에서 뺄 수 있습니다.

Tab은 오른쪽 이름 셀, Enter는 아래 이름 셀로 이동합니다. Shift+Tab은 왼쪽으로 이동합니다. Shift+Enter는 줄바꿈입니다. 이름 셀을 선택하고 엑셀 범위를 붙여넣으세요. 고정 열을 건너뛰며 따옴표로 감싼 셀의 탭과 줄바꿈을 보존합니다. 범위가 부족하면 행이나 이름 열을 먼저 추가하세요.

마지막 점부터 확장자를 보존합니다. .env는 확장자가 없는 이름으로 취급합니다. 자동 교정에서 ␣는 공백, ⇥는 탭, ↵는 줄바꿈을 나타냅니다.

기본 이름 끝 공백·점은 선택해서 정리할 수 있습니다. 확장자를 붙인 최종 이름의 끝 공백·점, 금지 문자, 예약 이름, 빈 이름, 중복은 적용을 차단합니다. 같은 폴더 안의 이름은 대소문자와 유니코드 정규화 차이까지 비교합니다.

저장할 파일의 용량·개수에 도구가 정한 상한은 없습니다. 폴더 저장은 파일을 하나씩 스트리밍하며, 파일별 다운로드는 각 원본 파일을 새 이름으로 브라우저에 전달합니다. 여러 다운로드가 차단되면 브라우저에서 허용하세요.

텍스트는 UTF-8로 읽고 줄바꿈을 LF로 통일합니다. 공백 제외 수치는 탭과 줄바꿈도 제외합니다. 오디오는 브라우저가 읽은 재생 시간을 초 단위로 내립니다. PNG·JPEG·GIF의 픽셀 크기, PNG pHYs·JPEG JFIF의 물리 해상도를 읽습니다. 다른 해상도 메타데이터는 확인 불가로 표시합니다.

페이지를 닫으면 작업이 종료됩니다.

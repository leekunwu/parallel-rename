# Parallel Rename

여러 파일 세트를 나란히 배치하고, 같은 행의 파일에 사용할 이름을 한 번에 구성하는 로컬 브라우저 도구입니다.

오디오·이미지·문서 등 서로 짝을 이루는 파일을 열별로 정리한 뒤, 순서·제목·구분자를 조합해 새 이름으로 사본을 저장할 수 있습니다. 설치나 서버 실행 없이 단일 HTML 파일로 동작합니다.

## 사용 예시

음원과 이미지 파일을 각각 파일 A·파일 B 열에 배치하고, 이름을 다음처럼 구성합니다.

| 행 | 파일 A | 파일 B | 순서 | 구분자 | 제목 | 변경 후 파일명 |
| --- | --- | --- | --- | --- | --- | --- |
| 1 | master_final.wav | cover_a.jpg | 01 | _ | Afterimage | 01_Afterimage.wav / 01_Afterimage.jpg |
| 2 | master_final_2.wav | cover_b.jpg | 02 | _ | Retrace | 02_Retrace.wav / 02_Retrace.jpg |

같은 행의 파일은 기본 이름을 공유하고, 각 원본의 확장자는 보존합니다.

## 시작하기

1. 저장소에서 `Parallel-Rename.html`을 다운로드합니다.
2. HTML 파일을 브라우저에서 엽니다.
3. 파일 한 세트를 창에 드래그앤드롭합니다.
4. 다른 세트를 추가할 때는 **추가**를 선택합니다. 새 파일 열이 생성됩니다.
5. 파일 순서를 확인한 뒤 이름 열·순서 열·구분자를 조합합니다.
6. 변경 후 파일명을 확인하고 **오류 확인·교정**을 실행합니다.
7. **파일별 다운로드** 또는 **폴더에 사본 저장**으로 결과를 저장합니다.

설치, 패키지 다운로드, 빌드 작업은 필요하지 않습니다.

## 주요 기능

- 파일 세트 드래그앤드롭 및 추가·교체
- 여러 파일 열을 같은 행 기준으로 연결
- 이름 열·순서 열·고정 구분자로 파일명 구성
- 이름 구성 미리보기와 변경 후 파일명 확인
- 열 제목 옆 손잡이 드래그로 순서 변경
- 헤더 더블클릭으로 열 이름 편집
- 파일 순서 변경 모드와 위·아래 이동 버튼
- 셀·범위·행·열·전체 선택 및 TSV 복사
- 엑셀·Google Sheets 범위 붙여넣기
- 실행 취소·다시 실행
- 파일명 검증 및 선택적 자동 교정
- 변경 계획 복사와 처리 로그 저장
- 파일별 다운로드 및 열별 폴더에 사본 저장
- 앱 안의 Guide

파일 열은 파일 열끼리, 이름 구성 열은 이름 구성 열끼리 이동합니다. 파일 열 순서와 실제 파일 순서 변경은 서로 다른 작업입니다.

## 매트릭스 조작

| 작업 | 조작 |
| --- | --- |
| 셀 선택 | 클릭 |
| 범위 선택 | 드래그 또는 Shift+클릭 |
| 행 전체 선택 | 행 번호 클릭 |
| 열 전체 선택 | 열 제목 클릭 |
| 표 전체 선택 | 왼쪽 위 모서리 클릭 |
| 이름 셀 편집 | 더블클릭 또는 선택 후 Enter |
| 편집 종료 | Esc |
| 선택 셀 이동 | 방향키 |
| 선택 범위 확장 | Shift+방향키 |
| 선택 영역 복사 | Cmd/Ctrl+C 또는 선택 복사 |
| 다음 이름 셀로 이동 | 편집 중 Tab |
| 이전 이름 셀로 이동 | 편집 중 Shift+Tab |
| 아래 이름 셀로 이동 | 편집 중 Enter |
| 셀 내부 줄바꿈 | 편집 중 Shift+Enter |
| 실행 취소 | Cmd/Ctrl+Z |
| 다시 실행 | Cmd/Ctrl+Shift+Z |

텍스트 입력 중에는 브라우저의 기본 텍스트 실행 취소가 적용됩니다. 작업 이력은 현재 페이지에서 최대 100개 상태를 보관합니다.

붙여넣기는 이름 열을 대상으로 하며, 고정 구분자·순서 열은 건너뜁니다. 행이나 이름 열이 부족하면 안내 메시지를 표시하므로 필요한 범위를 먼저 추가하세요.

**선택 복사**는 선택한 셀의 값을 복사합니다. **변경 계획 복사**는 파일 열·행·원래 이름·변경 후 이름을 포함한 전체 계획을 복사합니다.

## 파일명 검증과 교정

다음 항목을 검사합니다.

- 빈 이름
- 파일명에 사용할 수 없는 문자
- Windows 예약 이름
- 최종 파일명 끝의 공백·점
- 같은 출력 경로의 중복 이름
- 입력한 이름 끝에 포함된 원본 확장자

중복 비교에는 대소문자와 유니코드 정규화 차이를 반영합니다. 최종 이름에 오류가 있으면 저장을 차단합니다.

교정 화면에서는 금지 문자 대체, 탭·줄바꿈 정리, 이름 끝 공백·점 제거, 입력한 원본 확장자 제거 여부를 선택할 수 있습니다. 파일명 중간의 점은 유지하며 마지막 점을 기준으로 원본 확장자를 구분합니다. `.env`는 확장자가 없는 이름으로 취급합니다.

## 결과 저장

### 파일별 다운로드

각 원본 파일을 새 이름으로 다운로드하도록 브라우저에 요청합니다. 여러 파일 다운로드가 차단되면 브라우저에서 허용해야 할 수 있습니다. 실제 저장 여부는 브라우저 다운로드 목록에서 확인하세요.

### 폴더에 사본 저장

선택한 위치 안에 새 결과 폴더를 만들고, 파일 열의 헤더명을 하위 폴더명으로 사용합니다.

예를 들어 파일 열 이름이 `Audio`와 `Artwork`라면 다음처럼 저장됩니다.

- `Renamed-…/Audio/01_Afterimage.wav`
- `Renamed-…/Artwork/01_Afterimage.jpg`

폴더 저장은 브라우저의 `showDirectoryPicker` 지원과 보안 컨텍스트가 필요합니다. 지원 여부는 화면에 표시되며, 지원되지 않는 환경에서는 파일별 다운로드를 사용할 수 있습니다.

원본 파일 내용은 그대로 복사되며, 원본 경로의 파일을 직접 변경하지 않습니다.

## 파일 정보 확인

**정보 가져오기**로 일부 파일 정보를 확인할 수 있습니다.

- 텍스트의 글자 수 등 정보
- 브라우저가 읽을 수 있는 오디오의 재생 시간
- PNG·JPEG·GIF 이미지의 픽셀 크기
- 일부 PNG·JPEG에 기록된 물리 해상도

파일 형식과 메타데이터에 따라 확인할 수 없는 항목이 있습니다.

## 데이터 처리와 주의사항

- 파일 처리는 브라우저 안에서 수행합니다.
- 외부 API·CDN·서버 업로드를 사용하지 않습니다.
- 파일을 가져온 순서는 브라우저가 전달한 순서이므로, 파일 열마다 행의 대응 관계를 확인하세요.
- 페이지를 새로고침하거나 닫으면 파일 목록·입력 내용·작업 이력이 사라집니다.
- 실행 취소는 앱 내부 작업 상태에 적용됩니다. 이미 다운로드하거나 저장한 사본은 삭제되지 않습니다.
- 저장 완료·실패 내역은 처리 로그에서 확인하고 필요하면 로그를 내려받으세요.

## v0.8 변경 사항

- **열 이동** — 헤더의 ⠿ 손잡이를 끌고 세로 삽입선 위치에 놓습니다. 제목 클릭은 열 선택, 더블클릭은 이름 편집입니다.
- **순서 열** — 추가하면 이름 구성의 맨 앞에 들어갑니다. 이후 손잡이로 위치를 바꿀 수 있습니다.
- **매트릭스** — 원본 파일 열은 청회색, 이름 구성 열은 흰색, 변경 후 파일명 열은 연녹색으로 표시합니다.
- **도구 모음** — 넓은 화면에서는 미리보기와 파일 배치를 첫 줄에, 이름 구성과 작업 관리를 둘째 줄에 표시합니다.
